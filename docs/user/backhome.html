Hysteria2 回家配置

约 7 分钟阅读 · 公网访问家庭网络
回家服务用于在外部网络连接家中的 CMSingBox。当前页面支持 Hysteria2、DDNS/公网地址、UDP 端口、密码与 TLS 证书路径。

准备条件

  • 家庭网络有可从公网访问的 IPv4，或已正确配置 IPv6。
  • 没有固定公网地址时准备 DDNS 域名。
  • 准备域名对应的 TLS 证书和私钥文件。
  • 上级光猫/路由器允许把一个 UDP 端口转发到 CMSingBox。
运营商 CGNAT如果 WAN 地址是运营商内网地址，普通 IPv4 端口映射不会生效，需要申请公网 IP、使用 IPv6或另行建立中继。

后台配置

  1. 进入“高级设置 → 回家配置”。
  2. 开启 Hysteria2 回家服务。
  3. 服务器地址填写 DDNS 域名或公网 IP。
  4. 选择未占用的 UDP 端口，并设置高强度随机密码。
  5. 填写容器或主机内实际可读的 TLS 证书、私钥路径。
  6. 保存、应用配置并重启 sing-box。

Docker 中证书必须位于已挂载进容器的路径；只填写宿主机路径而未挂载，内核会因找不到文件而启动失败。

端口映射

在上级路由器建立 UDP 端口转发：公网端口 → CMSingBox IP 的同一 UDP 端口。不要误选 TCP。若 CMSingBox 直接拥有公网 IPv6，则配置防火墙允许该 UDP 端口，并限制后台 9092 不向公网开放。

客户端使用

保存成功后使用高级页面提供的移动端配置路径或下载链接，将配置导入支持 Hysteria2 的客户端。客户端中的服务器域名、端口、密码和 TLS 主机名必须与服务端一致。

验证

  1. 先在家中确认 sing-box 正常运行，日志没有证书或端口错误。
  2. 手机关闭 Wi-Fi，使用蜂窝网络测试，避免在内网做回环测试。
  3. 检查 DDNS 是否解析到当前公网地址。
  4. 检查上级路由 UDP 转发计数和 CMSingBox 日志。

安全建议

  • 使用独立随机密码，不要复用后台密码。
  • 证书私钥只保存在服务器，不上传公开仓库。
  • 只映射回家 UDP 端口，不把 9092、9090 直接暴露公网。
  • 修改证书、密码或端口后，客户端配置也要同步更新。
