CMSingBox

Sing-box 可视化管理平台

在浏览器中完成订阅、节点、分流规则、DNS、透明代理和运行维护。支持 Linux 原生、Docker Compose、RouterOS 容器及多种主路由分流方案。

快速开始 →功能教程GitHub

核心特性

围绕实际部署和长期维护设计

⚡

一键安装

Linux 原生脚本自动安装程序、基础内核和 systemd 服务。

◫

多平台部署

支持 amd64、arm64、armv7，提供原生程序、多架构镜像与 RouterOS 教程。

◎

轻量高效

Go 后端配合 React 前端，管理程序与 sing-box 内核独立运行。

▦

可视化管理

节点、规则、DNS、服务状态、更新和日志集中在一个后台。

⇆

多路由器分流

提供 RouterOS、爱快、UniFi、OPNsense 及通用路由器的 DNS、FakeIP、策略路由与回滚教程。

⌂

回家服务

内置 Hysteria2 回家配置，支持 DDNS、公网端口和 TLS 文件。

订阅定时刷新
