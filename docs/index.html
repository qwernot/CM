CMSingBox 中文文档

简单搭建稳定的旁路由代理环境

集中管理订阅、节点、HTTP/SOCKS5、透明代理与局域网 DNS；支持 Linux 原生、Docker Compose 和 RouterOS 容器部署。

快速开始 →Docker Compose

核心能力

一个后台完成日常管理

订阅订阅与节点

导入订阅、定时刷新并在代理控制台切换节点。

代理多种接入方式

HTTP/SOCKS5 混合代理、透明代理及局域网共享。

DNS独立 DNS 分流

按来源设备选择代理或直连上游，默认监听 53 端口。

开始使用

选择部署方式

推荐Linux 原生

二进制配合 systemd，不使用 Docker，适合服务器和小主机。

独立 IPDocker Compose

公开多架构镜像，使用 macvlan 独立局域网 IP，避免宿主机端口冲突。

ROS v7RouterOS 容器

使用 veth 独立 IP，适用于已开启 Container 功能的设备。

原生一键安装

不使用 Docker

curl -fsSL https://raw.githubusercontent.com/qwernot/CM/main/deploy/install.sh | sudo sh

安装后打开 http://服务器IP:9092，初始账号和密码均为 admin。首次进入后先添加订阅，再启动 Sing-box 服务。

首次配置

建议操作顺序

  1. 登录后台并修改管理员密码。
  2. 在“订阅管理”添加链接并更新节点。
  3. 在“系统设置”确认 HTTP/SOCKS5 混合代理与局域网访问。
  4. 在“服务管理”启动 Sing-box，再进入代理控制台选择节点。
  5. 需要局域网 DNS 时，进入“系统设置 → DNS 配置”，开启“独立 DNS 分流服务”，点击页面顶部“保存设置”，然后重启服务。
DNS 默认关闭：只有需要让局域网设备把 CMSingBox 当作 DNS 服务器时才开启。默认监听 0.0.0.0:53，Docker 容器使用独立 IP，因此不会占用宿主机 53 端口。
