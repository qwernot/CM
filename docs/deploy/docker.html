Docker Compose 独立 IP 部署

容器同时连接出口网络与 macvlan 局域网，为 CMSingBox 分配独立 IP。53、2080、9090、9092 均不占用宿主机端口。

一键部署 →

镜像说明

自动匹配设备架构

公开镜像为 darkver8/cmsingbox:latest，支持以下平台。Docker 会根据设备自动拉取对应版本，无需手动选择架构。

平台常见设备
linux/amd64Intel / AMD 服务器、NAS、小主机
linux/arm6464 位 ARM 软路由、树莓派、NAS
linux/arm/v732 位 ARMv7 设备
基础内核已集成：镜像首次启动会自动把随镜像提供的 Sing-box 内核写入数据目录，可直接工作；后续仍可在后台按需更新内核。

方式一 · 推荐

一键部署

  1. 安装 Docker Engine 与 Docker Compose 插件。
  2. 从路由器 DHCP 地址池外选择一个空闲 IP，例如 192.168.1.20。
  3. 执行下面命令，把 IP 替换成你的实际地址。
curl -fsSL https://raw.githubusercontent.com/qwernot/CM/main/deploy/install-docker.sh | sudo env CMSINGBOX_IP=192.168.1.20 sh

脚本会识别默认网卡与网段，默认网关使用 192.168.1.1，创建 macvlan 网络、拉取多架构镜像并启动容器。

多网卡或非默认网段请显式指定：

curl -fsSL https://raw.githubusercontent.com/qwernot/CM/main/deploy/install-docker.sh | sudo env \
  CMSINGBOX_IP=192.168.1.20 \
  CMSINGBOX_PARENT=eth0 \
  CMSINGBOX_SUBNET=192.168.1.0/24 \
  CMSINGBOX_GATEWAY=192.168.1.1 sh

方式二 · 手动

Docker Compose 部署

先确认物理网卡名称、局域网网段及待分配 IP：

ip -4 route
ip -br link
ping -c 1 192.168.1.20

创建 macvlan 网络。下面以 eth0、192.168.1.0/24 为例：

docker network create -d macvlan \
  --subnet=192.168.1.0/24 \
  --gateway=192.168.1.1 \
  -o parent=eth0 cmsingbox_lan

创建空目录，在其中保存下面的 compose.yml：

services:
  cmsingbox:
    image: darkver8/cmsingbox:latest
    container_name: cmsingbox
    restart: unless-stopped
    privileged: true
    environment:
      TZ: Asia/Shanghai
    volumes:
      - ./data:/data
    networks:
      egress:
        gw_priority: 1
      lan:
        ipv4_address: 192.168.1.20

networks:
  egress:
    driver: bridge
  lan:
    external: true
    name: cmsingbox_lan

拉取并启动：

docker compose pull
docker compose up -d
docker compose ps
docker compose logs --tail=100 cmsingbox
为什么要两个网络：lan 提供独立局域网 IP，egress 提供默认互联网出口。缺少出口网络时，容器内可能无法下载订阅或更新内核。

首次使用

登录并启动服务

  1. 浏览器打开 http://192.168.1.20:9092。
  2. 初始账号和密码均为 admin，登录后建议立即修改。
  3. 添加订阅并执行更新，然后进入“服务管理”启动 Sing-box。
  4. 代理控制台使用 http://192.168.1.20:9090/ui/；HTTP/SOCKS5 混合代理地址为 192.168.1.20:2080。

DNS

DNS 默认关闭，按需开启

  1. 进入后台“系统设置”。
  2. 找到“DNS 配置”，开启“独立 DNS 分流服务”。
  3. 监听 IP 保持 0.0.0.0，监听端口保持 53。
  4. 点击页面顶部“保存设置”，再重启 Sing-box 服务。
  5. 把路由器或客户端 DNS 设置为容器独立 IP，例如 192.168.1.20。
如果 53 端口无法启动，先检查该容器 IP 上是否已有 DNS 服务。macvlan 独立 IP 不会与宿主机的 53 端口冲突。

维护

更新、日志与备份

cd /opt/cmsingbox-docker

# 更新到最新镜像
docker compose pull
docker compose up -d

# 查看状态和日志
docker compose ps
docker compose logs -f --tail=100

# 停止但保留数据
docker compose down

一键脚本的持久数据保存在 /opt/cmsingbox-docker/data。升级前备份此目录；不要使用 docker compose down -v。

网络提示

宿主机可能无法直接访问容器

这是 macvlan 的默认隔离行为，不代表 CMSingBox 故障。同一局域网中的手机、电脑和路由器通常可以直接访问容器 IP。部分无线网卡、云服务器或禁止多 MAC 地址的网络不支持 macvlan，此时请改用 Linux 原生部署。
