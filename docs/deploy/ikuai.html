爱快按设备分流教程

约 10 分钟阅读 · 爱快 3.7.23 实测 · IP 分组 / DNS DNAT / 下一跳
本教程按照爱快免费版 3.7.23 的实际界面编写。示例中爱快 LAN 为 192.168.8.1/24，CMSingBox 为 192.168.8.6。只有加入 proxy_device 的设备才走 CMSingBox，其他设备的 DNS 和上网方式保持不变。
禁止把 CMSingBox 自身加入代理设备组192.168.8.6 不能加入 proxy_device，否则其订阅、DNS 和节点连接会再次送回自身，形成环路。

一、确认网络结构

项目本教程实测值其他网络如何填写
爱快 WAN192.168.1.4/24不参与本教程的 LAN 分流填写
上级网关192.168.1.1保持现有配置
爱快 LAN192.168.8.1/24填写客户端所在 LAN 的爱快地址
客户端地址192.168.8.20–192.168.8.200以爱快 DHCP 地址池为准
CMSingBox192.168.8.6填写 CMSingBox 的固定 LAN 地址

CMSingBox 与需要分流的客户端应能通过爱快 LAN 相互访问。不要照抄其他教程中的 192.168.1.20；所有地址必须以自己的拓扑为准。

二、准备 CMSingBox

  1. 确认 192.168.8.6 使用固定地址，并且不在动态 DHCP 地址池内。
  2. 进入 CMSingBox“系统设置 → DNS 配置”，开启独立 DNS，监听 0.0.0.0:53。
  3. 进入“高级配置”，确认 FakeIP 网段。默认值为 198.18.0.0/15；如果这里改过，爱快目标组必须使用相同网段。
  4. 开启透明代理，保存并应用 sing-box 配置，然后应用透明代理规则。
  5. 先确认 HTTP/SOCKS5 显式代理可用，再继续配置爱快。

三、建立两个 IP 分组

正确入口是“网络设置 → 终端分组设置 → IP分组”。部分旧教程写成“分流设置 → IP 分组”，在爱快 3.7.23 中并不存在。

1. 设备组 proxy_device

创建名为 proxy_device 的分组，只加入需要代理的终端固定 IP。爱快不允许空 IP 分组；尚未选择设备时可暂时填写 DHCP 池外的占位地址：

192.168.8.254 待替换占位地址

以后只需编辑这个分组：加入设备即启用分流，移除设备即恢复直连。建议先在“DHCP设置 → DHCP静态分配”中固定终端地址。

2. 目标组 proxy_cidr

创建名为 proxy_cidr 的分组，至少加入 CMSingBox 后台显示的 FakeIP 网段：

198.18.0.0/15 CMSingBox FakeIP

Telegram 等直接连接纯 IP 的应用可把相应网段继续加入 proxy_cidr。不要把 192.168.8.0/24 加入目标组。

四、只劫持所选设备的 DNS

进入“网络设置 → NAT规则 → 添加”，创建一条规则：

字段填写值
动作目的地址NAT
进接口lan1
源地址选择 proxy_device
目的地址留空，表示任意 DNS 地址
协议tcp+udp
目的端口53
NAT地址192.168.8.6
NAT端口53
备注CMSingBox-DNS

爱快 3.7.23 可直接选择 tcp+udp，因此一条规则即可同时处理 TCP 与 UDP DNS。DHCP 中原有的公共 DNS 可以保持不变；只有 proxy_device 中的设备会被重定向。

五、把 FakeIP 流量送到 CMSingBox

进入“流控分流 → 分流设置 → 端口分流 → 添加”，填写：

字段填写值
分流方式下一跳网关
下一跳网关192.168.8.6
协议tcp+udp
源地址选择 proxy_device
目的地址选择 proxy_cidr
生效周期全选
生效时间00:00-23:59
备注CMSingBox-FakeIP

这条规则按“来源设备 + 目标网段”匹配，不会让所有 LAN 设备全局走旁路由。若爱快已有其他端口分流规则，应确保本规则优先命中。

六、以后选择或取消设备

  1. 进入“网络设置 → 终端分组设置 → IP分组”。
  2. 编辑 proxy_device。
  3. 删除占位地址 192.168.8.254，加入需要代理的终端 IP，一行一个。
  4. 保存后让终端断开并重新连接网络，或清除一次 DNS 缓存。
  5. 不再需要代理时，从 proxy_device 删除该终端；不要删除两条基础规则。

七、验证

  1. 未加入 proxy_device 的设备应继续使用原来的 DNS 和线路。
  2. 加入分组的设备查询代理域名时，应得到 198.18.0.0/15 中的地址。
  3. 爱快“分流监控”中应看到 CMSingBox-FakeIP 命中。
  4. CMSingBox“DNS 监控”应出现终端查询，代理控制台应出现连接。
  5. 分别测试国内网页、Google 和仅使用纯 IP 的应用。

八、断网回滚

  1. 先停用端口分流规则 CMSingBox-FakeIP。
  2. 再停用 NAT 规则 CMSingBox-DNS。
  3. 终端重新连接网络并清除 DNS 缓存。
  4. 无需修改爱快 WAN、LAN 或原有 DHCP DNS。
解析正常但网页打不开先核对 CMSingBox 的 FakeIP 网段与 proxy_cidr 是否完全一致，再检查透明代理是否已经应用；仅开启 DNS 不能转发 FakeIP 流量。
