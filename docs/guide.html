快速开始

约 8 分钟阅读 · Linux / Docker / fnOS / RouterOS
CMSingBox 是 sing-box 的可视化管理平台。选择一种部署方式后，按照“登录 → 添加订阅 → 应用配置 → 启动服务”的顺序即可开始使用。

选择部署方式

方式适合场景网络特点
Linux 原生服务器、虚拟机、Linux 小主机直接使用宿主机 IP 和端口
Docker ComposeNAS、Linux Docker 主机macvlan 独立 IP，避免宿主机端口冲突
飞牛 fnOS FPK飞牛 NAS 应用中心手动安装安装向导创建独立 IP，隔离飞牛 DNS 53
RouterOS 容器已启用 Container 的 RouterOS v7veth 独立 IP，可配合 ROS 按设备分流

支持架构

架构常见设备镜像选择
amd64Intel / AMD 服务器、NAS、小主机darkver8/cmsingbox:latest 自动匹配
arm6464 位 ARM 路由器、树莓派、NAS
arm/v732 位 ARMv7 设备

Linux 一键安装

curl -fsSL https://raw.githubusercontent.com/qwernot/CM/main/deploy/install.sh | sudo sh

脚本安装 CMSingBox、内置基础内核和 systemd 服务。完成后访问 http://服务器IP:9092。详细参数见 Linux 原生部署。

Docker 一键安装

先从路由器 DHCP 地址池外选一个空闲地址。下面示例使用 192.168.1.20，网关默认为 192.168.1.1。

curl -fsSL https://raw.githubusercontent.com/qwernot/CM/main/deploy/install-docker.sh | sudo env CMSINGBOX_IP=192.168.1.20 sh

需要自行维护 Compose 或查看网络原理，请阅读 Docker Compose 部署。

首次使用

  1. 浏览器打开 http://CMSingBox-IP:9092，初始账号与密码均为 admin。
  2. 进入“设置 → 安全”，修改后台密码。
  3. 进入“节点与订阅”，添加订阅链接并刷新；也可添加手动节点。
  4. 按需建立筛选组和路由规则，在设置页检查混合代理、DNS、最终出站。
  5. 保存设置并应用配置，然后启动或重启 sing-box。
  6. 代理控制台地址为 http://CMSingBox-IP:9090/ui/，混合代理默认为 CMSingBox-IP:2080。
DNS 不会擅自接管网络独立 DNS 服务默认关闭。要使用它，请在设置中开启并保存，再让路由器或终端把 DNS 指向 CMSingBox IP。

默认端口

端口协议用途
9092TCPCMSingBox 后台
9090TCPClash API 与代理控制台
2080TCPHTTP / SOCKS5 混合代理
53TCP / UDP独立 DNS 服务，默认关闭

除原生安装的后台端口需通过安装参数修改外，其余端口可在后台设置中调整。
