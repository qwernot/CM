总授权中心部署

查看流程 →

授权架构

一个总授权端，签发任意设备

客户把六位设备码发给管理员，管理员设置订阅链接额度和有效期并生成授权码。客户机器不需要与授权端处于同一服务器、同一局域网，也不需要联网访问授权端。

单独部署

仅授权管理员执行

curl -fsSL https://raw.githubusercontent.com/qwernot/CM/main/install-license.sh | sudo env CMSINGBOX_LICENSE_PASSWORD='Aa666333' sh

默认端口为 9093。首次安装会生成私钥和公钥，数据位于 /opt/cmsingbox-license/license-data。首次登录密码为 Aa666333，建议部署完成后使用更强的自定义密码重新安装。

private.key 必须离线备份，绝不能上传 GitHub。丢失私钥后无法继续签发与原公钥匹配的许可证。

公钥匹配

客户程序必须使用对应公钥

安装脚本会输出授权公钥。部署客户 CMSingBox 时传入：

curl -fsSL https://raw.githubusercontent.com/qwernot/CM/main/install.sh | sudo env CMSINGBOX_IP=192.168.1.20 CMSINGBOX_LICENSE_PUBLIC_KEY='授权端输出的公钥' sh

签发流程

生成授权码

  1. 访问 http://授权服务器IP:9093 并登录。
  2. 填写客户设备码、订阅链接额度、有效期和授权编号。
  3. 生成并复制 CMS1 开头的授权码。
  4. 客户在 CMSingBox“系统设置 → 软件授权”中激活。
