首次配置

功能使用

完成登录、订阅、sing-box 内核、HTTP/SOCKS5 和 DNS 的基础配置。

开始配置 →

首次登录

打开管理后台

访问 http://CMSingBox-IP:9092，初始账号和密码均为 admin。登录后先到系统设置修改密码。

节点与订阅

添加第一条订阅

  1. 进入“节点与订阅”，填写订阅名称和 URL。
  2. 保存并刷新，确认已解析出节点。
  3. 未授权最多添加一条订阅链接；订阅内节点数和手动节点数不限制。
  4. 在系统设置中下载 sing-box 内核并应用配置。

显式代理

HTTP 与 SOCKS5

在设置中开启“允许局域网访问”。客户端服务器填写 CMSingBox 独立 IP，端口默认 2080。

curl -x http://用户名:密码@192.168.1.20:2080 https://api.ipify.org
curl -x socks5h://用户名:密码@192.168.1.20:2080 https://api.ipify.org
代理暴露到不受信网络时必须开启认证。后台登录密码和代理密码是两套独立凭据。

DNS

启用 53 端口

macvlan 独立 IP 下，容器的 53 端口不会与宿主机冲突。启用后，局域网设备可将 DNS 指向 CMSingBox IP。修改前确认上游 DNS 和分流模式正确。
