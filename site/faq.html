常见问题

从容器网络、端口、订阅、sing-box 与认证状态依次定位问题。

开始排查 →

Docker 网络

后台无法访问

  • 确认客户端与 CMSingBox IP 在同一网段。
  • 确认 IP 不在 DHCP 池内且未被其他设备占用。
  • 确认 parent 是实际连接局域网的物理网卡，不能填写 docker0。
  • 无线网卡或云平台可能不支持 macvlan 多 MAC。
cd /opt/cmsingbox
docker compose ps
docker compose logs --tail=100
docker network inspect cmsingbox_cmsingbox_lan

正常现象

宿主机访问不了，但其他设备能访问

macvlan 默认隔离宿主机和容器。如果手机、电脑能访问，说明 CMSingBox 正常。普通用户无需处理。

sing-box

服务反复重启

  1. 确认订阅已成功解析并至少存在一个有效节点。
  2. 查看 sing-box 日志中的第一个配置错误。
  3. 检查自定义入站、出站和规则 JSON。
  4. 更新订阅后重新生成并应用配置。

代理认证

返回 407

表示 HTTP/SOCKS5 认证已开启但用户名或密码不正确。请使用系统设置中的代理凭据，不要误用后台管理员密码。
