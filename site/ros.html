RouterOS 容器部署

在支持 Container 的 RouterOS v7 设备上，通过 veth 为 CMSingBox 分配独立地址。

查看要求 →

前提条件

先确认设备支持

  • RouterOS v7，已安装与系统版本匹配的 Container 包。
  • 设备架构为 amd64、arm64 或 armv7。
  • 建议使用外置磁盘保存 root-dir 和数据，避免占满内置闪存。
  • 开启 container device-mode 需要物理确认。
RouterOS 官方明确提示容器会扩大攻击面。只使用可信镜像并限制后台访问来源。

veth 网络

示例：为容器分配 192.168.1.20

请把 bridge、网段和地址换成自己的环境：

/system/device-mode/update container=yes

/interface/veth/add name=veth-cmsingbox address=192.168.1.20/24 gateway=192.168.1.1
/interface/bridge/port/add bridge=bridge interface=veth-cmsingbox

完成 device-mode 物理确认后继续，CMSingBox IP 必须位于 DHCP 地址池之外。

拉取容器

从项目镜像仓库部署

下面命令会让 RouterOS 按设备架构选择 amd64、arm64 或 armv7 镜像，并把数据保存到外置磁盘：

/container/config/set registry-url=https://ghcr.io tmpdir=disk1/tmp
/container/mounts/add list=cmsingbox-data src=disk1/cmsingbox-data dst=/data
/container/add remote-image=ghcr.io/qwernot/cmsingbox:latest interface=veth-cmsingbox root-dir=disk1/cmsingbox-root mountlists=cmsingbox-data logging=yes start-on-boot=yes
/container/print
/container/start 0

容器解压完成后再执行 start。访问 http://192.168.1.20:9092，初始账号和密码均为 admin。

RouterOS 容器重点支持管理后台与 HTTP/SOCKS5 显式代理。透明代理、TUN 和宿主机防火墙管理依赖设备能力，不在本教程承诺范围内。
