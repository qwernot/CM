CMSingBox 中文文档

简单、清楚地部署 CMSingBox

从 Docker 独立 IP、RouterOS 容器到订阅、HTTP/SOCKS5 和 DNS，按步骤完成安装与首次使用。

开始阅读 →

开始使用

选择部署方式

推荐Docker / NAS

使用 macvlan 独立局域网 IP，避免与宿主机端口冲突。

实验性RouterOS 容器

使用 veth 独立 IP，适用于支持 Container 的 ROS v7 设备。

安装完成后首次配置

登录后台、添加订阅、下载内核并验证 HTTP/SOCKS5。

CMSingBox IP 必须位于当前局域网网段内、处于 DHCP 自动分配范围之外，并确认没有其他设备占用。

Docker 一键安装

准备一个空闲 IP 后执行

curl -fsSL https://raw.githubusercontent.com/qwernot/CM/main/install.sh | sudo env CMSINGBOX_IP=192.168.1.20 sh

把示例 IP 改成实际地址。安装后打开 http://CMSingBox-IP:9092，初始账号和密码均为 admin。
