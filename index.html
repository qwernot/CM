开始使用

选择部署方式

默认Linux 原生

二进制配合 systemd，不使用 Docker，适合普通服务器和小主机。

独立 IPDocker / NAS

使用 macvlan 独立局域网 IP，避免与宿主机端口冲突。

实验性RouterOS 容器

使用 veth 独立 IP，适用于支持 Container 的 ROS v7 设备。

原生一键安装

不使用 Docker

curl -fsSL https://raw.githubusercontent.com/qwernot/CM/main/deploy/install.sh | sudo sh

安装后打开 http://服务器IP:9092，初始账号和密码均为 admin。Docker 与 RouterOS 是另外两种部署方式。
