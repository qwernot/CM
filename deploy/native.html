默认一键部署

Linux 原生部署

直接安装 CMSingBox 二进制并由 systemd 管理，不经过 Docker。

开始部署 →

一键安装

适用于 systemd Linux

curl -fsSL https://raw.githubusercontent.com/qwernot/CM/main/deploy/install.sh | sudo sh

安装后访问 http://服务器IP:9092，初始账号和密码均为 admin。

需要修改后台端口时，在安装命令中指定：

curl -fsSL https://raw.githubusercontent.com/qwernot/CM/main/deploy/install.sh | sudo env CMSINGBOX_PORT=19092 sh

端口说明

原生服务使用宿主机 IP

后台 9092、混合代理 2080、DNS 53 都直接使用宿主机端口。后台端口可在安装时改，代理和 DNS 端口可在 CMSingBox 设置中修改。

如果宿主机已有 DNS、代理或后台服务，应先检查端口占用。希望完全避免端口冲突时，请改用 Docker 独立 IP 部署。
ss -lntup | grep -E ':53|:2080|:9092'

日常管理

状态、日志和更新

systemctl status cmsingbox --no-pager
journalctl -u cmsingbox -f -n 100
systemctl restart cmsingbox

# 更新：重新执行一键安装命令

程序位于 /opt/cmsingbox，数据位于 /var/lib/cmsingbox。重新安装不会删除数据。
