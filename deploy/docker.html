推荐部署方式

Docker 独立 IP 部署

为 CMSingBox 容器分配独立局域网 IP，使 53、2080、9092 不占用宿主机端口；镜像已包含基础内核和 HTTPS 根证书。

开始部署 →

部署前

确认网络参数

  1. 宿主机必须是 Linux、NAS 或虚拟机，并已连接到局域网。
  2. 从路由器 DHCP 地址池外选择一个空闲 IP。例如宿主机为 192.168.1.232，可以为 CMSingBox 预留 192.168.1.20。
  3. macvlan 在部分无线网卡、云服务器和禁止多 MAC 地址的网络中不可用。
ip -4 route
ip -br link
ping -c 1 192.168.1.20
ping 没回应不能百分之百证明 IP 空闲，还应检查路由器租约与静态地址列表。

一键安装

自动识别网卡、网段和网关

curl -fsSL https://raw.githubusercontent.com/qwernot/CM/main/deploy/install-docker.sh | sudo env CMSINGBOX_IP=192.168.1.20 sh

复杂网络可显式覆盖参数：

curl -fsSL https://raw.githubusercontent.com/qwernot/CM/main/deploy/install-docker.sh | sudo env \
  CMSINGBOX_IP=192.168.1.20 \
  CMSINGBOX_PARENT=eth0 \
  CMSINGBOX_SUBNET=192.168.1.0/24 \
  CMSINGBOX_GATEWAY=192.168.1.1 sh

日常管理

更新、日志和停止

cd /opt/cmsingbox-docker
docker compose ps
docker compose logs -f --tail=100
docker compose restart

# 更新：重新执行 Docker 一键安装命令
# 停止但保留数据
docker compose down

持久数据位于 /opt/cmsingbox-docker/data，不要随容器一起删除。

macvlan 说明

宿主机默认不能直接访问容器

这是 macvlan 的默认隔离行为，不是 CMSingBox 故障。同一局域网中的手机、电脑和路由器仍可直接访问 CMSingBox IP。普通部署不建议增加 macvlan shim。
